## Cutin：已观察

- 326 CommandEffect parser 接收名称、资源及三个可选整数，整数默认 -1；325 Execute → 329 004de800 分派。
- 328 0050ea30 构造器：第一个整数为停留 ticks（10ms），第二个整数为加速参数，符号决定方向。不是把第一个整数当速度。
- 加速倍率 abs(rate/100)，<=1 回退到1.5；初速度±2，每次更新先截断成整数位移，再乘倍率。
- rate>=0：从 x=-width 向右滑入，停在0，最终向右滑出；rate<0：从 x=800 向左滑入，最终向左滑出。
- 324 / 332 更新：初次调用使用1tick，此后至少4tick才更新。进入完成后才计停留时间；负停留持续等待；336 fadeout 设置退出请求，进入完成后再退出。
- 进入、停留、退出三个阶段；退场超出画布后完成。运动不阻塞脚本。语料中显式 wait、stage、fadeout 共同编排。
- 构造器会尝试加载同名声音；当前已导入资源目录中，八次实际调用的图名没有同名音频条目。
- 全部语料切入图都是800×600，透明内容仍保留完整画布。移植当前严格限制该画布及有界参数范围。

## WScroll2：已观察

- 38次物理源码调用（含补丁重复），均为 `.effect WScroll2 * 60 -2`。前接背景、第一前景和边框组成的步行场景。
- 327 构造、331 初始化、322 / 338 更新、343 场景重绑定、330 00509be0 循环复制。
- 背景和第一前景按各自源图宽度取模，负余数修正；跨边界时复制源图另一端，不能让循环处露黑。
- 第一前景位移由 speed*ticks/10 产生。背景按累积余量/5 产生远近差；仅 abs(remainder)>5 时推进，不是 >=5。
- phase 每次绘制递减并模 period，sin(phase*2π/period) 与边框超屏尺寸决定起伏；更新 engine 的边框 crop。
- 当前支持普通 StageInfo 路径，第一前景初始裁切沿用居中布局（语料center=0、宽3200 → crop1600）。另一 StageInfo 标志路径、对象列表、wscroll2pause / wscroll2Ratio 等没有在语料中启用，暂未接入。
- 相同参数重复命令在原版分派早退，不重启动画。新stage重绑定图像，时间相位继续。
- 原版 end 设置结束标志，析构会把最后的特效画布复制回主舞台。移植停止时冻结当前采样，下一stage可替换。

## 移植选择与验证边界

- Cutin 使用首次10ms、之后40ms的固定采样格；Walking 使用安装配置 effectDrawInterval=10 对应的100ms采样。时间分片与大步无头推进可重现；原版绘制调用、D3D/软件路径及全局时钟相位不同，未声称逐帧一致。
- 固定采样下 Walking 的 period60对应6秒正弦周期；取绝对值后的可见起伏周期为3秒。背景负向移动、5:1远近差、严格余量阈值与边框超屏裁切均有独立单元检查。
- 普通图像缓存改为512MiB：两张4×长背景约234MiB，加8×边框约123MiB，合计约357MiB；256MiB无法容纳它们，会持续淘汰。
- 仍保留全部原画布、alpha、滤色、层角色和旧快照；不会裁掉切入图的透明边。
- WScroll2 仅实现当前语料的60/-2与普通布局，不支持对象列表/自定义比例/暂停变量/Walking fadeout；未知形式继续严格停止。
- 两变体开场均严格 trace 1694消息到第一处分支选项；备注兼容只覆盖全角分号，其他未知输入仍严格停止。
- 核心运动、参数拒绝、大步时间、相位分片、材质与快照、effect end以及GPU循环/切入/露出下层测试通过。23项dev、17项ASan通过；普通缓存调整后5项GPU回归通过。
