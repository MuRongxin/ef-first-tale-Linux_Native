# 产品决策

本文记录当前移植版的产品要求，供开发、验收和后续 UI 实现使用。原版格式与行为取证保留为事实参考，不自动成为移植版的产品要求。

## 所有内容默认开放（2026-10-28）

用户确认：**游戏内容全部直接可玩，不需要解锁。**

- 章节、CG 图鉴、回想与音乐鉴赏默认全部开放。
- 内容入口不得依赖通关、已读、观看次数、跨周目标记、CG 登记或旧存档导入；新安装和空存档目录也应可以访问全部内容。
- 不实现用于限制内容访问的 CG 解锁或跨周目解锁机制，也不要求玩家先完成一轮游戏。
- 已读记录可用于“跳过已读”等体验，但不得用来隐藏、禁用或阻止内容访问。
- 正常剧情中的选项、分支及会话变量继续按剧本执行；全内容开放通过相应章节/鉴赏入口提供，不改写剧情分支逻辑。
- 原版 `.tbr`、`cgv.dat` 及其它进度标记的逆向说明保留；如后续实现旧档迁移，不能把迁移结果当成开放内容的前提。

标题菜单与章节选择已接入：新游戏、继续、读取、全开放的序章/第一章/幕间/第二章、确认返回标题及退出。图鉴、回想和音乐鉴赏界面尚待接入；标题外观仍待原版校准。入口状态见 [标题流程](TITLE-FLOW-20261028.md)。

## 后续工作顺序

1. 标题与流程入口已接通，继续原版布局与外观校准。
2. 存读档界面收尾：备注、原版标题/按钮状态、菜单音效与动画。
3. 全开放的图鉴、回想与音乐鉴赏。
4. 按需补充已读记录、独立体验偏好和旧档迁移；不增加内容解锁依赖。

## 验收约束

使用空用户数据目录启动，章节/鉴赏入口不因无通关或已读记录而锁定；加载旧档、清除已读记录或迁移失败也不得重新锁定内容。已读跳过功能与内容开放策略分别验证。
