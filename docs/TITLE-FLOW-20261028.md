# 标题、章节入口与会话生命周期

默认 `./build/dev/ef_native --content content` 进入标题，提供新游戏、继续、读取存档、章节选择和退出。继续按保存顺序选择最近的兼容普通或快速槽位；无存档时提示并保留标题。读取界面允许浏览空槽，标题下禁用保存模式切换。菜单支持鼠标、上下键与回车。

游戏内按 Esc 确认返回标题，取消不会推进对白。确认后先销毁电影播放器，再关闭音频输出，最后释放剧本、Presentation、消息窗与 mixer，清除纹理/转场缓存及待处理存档请求。正常脚本结束也回到标题。标题退出及窗口关闭均确认；F11 切换无边框全屏。显式 `--script` / `--load-save` / `--load-slot` 仍保留开发直达流程和原有 Esc 行为。

## 章节入口核对

依据现有 `docs/SAVE_FORMAT.md` 章节结构和当前 content 的导入 JSON 指令，观察如下。这里描述导入剧本事实，不声称是原 exe 的菜单调用实现。

| 入口 | 脚本，从首条指令执行 | 初始化与首次演出 |
|---|---|---|
| 序章 / 新游戏 | `scr/000_01mugai.sc` | 雪花、黑底、panel 3，随后按剧本加载画面与音频 |
| 第一章 | `scr/100_01.sc` | WHITE → `terop_10001a.png` → WHITE；`efBGM025mix.ogg`；`ev01_sky_a_sepia.png`、panel 1 |
| 幕间 | `scr/700_01mugai.sc` | WHITE；`efBGM026mix.ogg`；`vista_window2.png`、纵向滚动及 panel 3 |
| 第二章 | `scr/200_01.sc` | WHITE → `ago_base_second.png` → WHITE → `ago_base_20001a.png`、panel 1；开头没有 BGM，之后按剧本播放 SE/音频 |

每次新建独立 VM 与 Presentation，panel 初始隐藏、背景黑色、所有音频静止、局部变量为空。不使用 `--start-line`，不重放此前剧情，不读取用户已读/通关状态。

移植入口策略：`censored=0`；`EYE_SEQ_DEFAULT` 为 e 的 3 / j 的 2（来自 test.sc 和 j 各入口赋值）。第一章及以后的入口设 `ef_000=1`，第二章再设 `ef_700=1`，对应前序脚本结束时的赋值。其余剧情变量从新会话的零值开始，之后选择照常执行，不伪造此前的好感度/选项历史。幕间本身仍执行首次进入分支。所有入口常驻可选，不以这些变量判定是否开放。

`--chapter 0|1|2|3` 使用同一初始化路径，可配合 `--variant e|j`、`--trace-messages` 检查入口。与 `--script` 及恢复存档互斥。

## 验证

`ctest --preset dev -R title_flow --output-on-failure` 使用合成资源与实际 SDL dummy 音频回调，在空存档目录启动，通过窗口键盘/鼠标输入依次进入全部四个入口、保存并核对变量、取消返回、确认释放、继续最近存档、标题菜单读取、新游戏及退出。测试还检查标题读档菜单不能切入保存模式，章节之间不残留局部变量或 BGM，确认输入不推进对白。

FFmpeg 构建另有 `title_movie_return`：生成 30 秒 H.264/AAC 电影，在不可跳过的电影播放中取消返回，再确认返回，连续两次释放实际解码线程与音频输出；未等电影自然结束。测试不依赖游戏素材。

本机真实包验收：四个入口的 e/j 各执行 100 条对白，共 800 条，均通过；幕间正常进入第二章，第二章进入 201_01。实际窗口在空槽目录依次进入四个入口，检查首段对白、图像、BGM、保存、返回标题、继续及新游戏；SDL dummy 回调启用与无声时钟两种运行均通过。实际 checkpoint 核对第一章 BGM025、幕间 BGM026、第二章首段没有音轨；后者确认不会继承前一章节的 BGM。标题及四章截图已人工检查，未做原版逐像素对照，也不把 dummy 设备测试表述为扬声器听感验收。

可复查本地素材流程：

```bash
xvfb-run -a python3 tests/title_flow_smoke.py --real-content content --out work/title-flow/window --audio
```

报告、截图、存档均放在 build/work，不入库。本轮未改 PAZ、导入器或资源清单逻辑。受影响的 VM、checkpoint 与 ScriptView 三项 ASan/UBSan 定向测试通过；开发全量结果见进度记录。
