# 超宽背景分块渲染与后台预取

## 实现范围

剧情场景与图鉴高清查看共用 `Renderer` 的分块路径。普通窗口仍选 4×，最大化/无边框全屏仍选 8×；不按显示器分辨率改选档位。运行时仅从 `content/` 读取图像，不改包、不读原归档。

当真实像素任一边超过 GL 限制或 8,192，或完整 RGBA 大于 128 MiB 时，保留至多 2,048 边长的预览纹理，同时使用原档像素生成 1,024×1,024 分块。每块四边保留一像素相邻样本，双线性过滤不在块边缘重复错误的像素。可见范围按图层矩形与 800×600 设计视口求交；atlas 裁剪、底部裁切、alpha、HSV→overlay→screen 均保持原图坐标。转场 FBO 在新细节上传后失效重绘；旧画面未补齐细节时继续刷新请求，防止冻结快照让后台误判过时。

## 后台与预算

- 一个后台 worker 完成分块缓存生成、磁盘读取和解压，GL 上传/销毁只在窗口线程执行。
- 非交错 PNG 逐行读取，最多保留 1,026 行；40,432 宽图像的扫描带约 158 MiB，不展开约 740 MiB 的整图 RGBA。扫描带上限 192 MiB。WebP 使用既有完整解码预算（512 MiB）；交错 PNG 当前保留预览并报告不支持分块。
- GPU 分块缓存上限 192 MiB；每帧上传额度 16 MiB（最后一块可略超额度），远离当前视口一圈以上的块被回收。普通纹理 LRU 512 MiB、滤色色带 4 MiB 保持独立。
- 可见块优先，额外预取至多 12 个邻块到 CPU，待上传总量上限 64 MiB，其中保留 16 MiB 给可见块，防止多个图层的预取占满队列；滚动后先消费已预取结果。快速切图/离开场景会取消过时准备，清缓存使用 generation 隔离已在执行的任务。
- 磁盘缓存位于 `$XDG_CACHE_HOME/ef-native/tiles-v1`（回退 `$HOME/.cache/ef-native/tiles-v1`），按源路径、文件大小、修改时间、像素尺寸区分。使用 zlib 无损块；临时目录生成完毕后原子发布，损坏/丢失的块从源重新生成；完成缓存按年龄清理至约 2 GiB（当前正在生成的源除外）。删除该目录只影响性能。

## 首次加载边界

预览仍使用既有同步缩小解码，因此首次进入新背景仍有一次解码开销；后台随后完整扫描一次压缩源，建立可随机读取的磁盘分块缓存。缓存生成阶段不把整张图上传 GPU。滚动不再重新解码整个 PNG。

任一可见范围超过 44 块的缩小总览使用预览，放大至可管理的视口范围后切到原倍率分块。分块失败（例如缓存目录不可写）会记录原因并继续显示预览。这里没有实现 KTX2，也不把短暂预览描述为已加载原倍率细节。

## 验证命令

```bash
cmake --build --preset dev
ctest --preset dev
ctest --test-dir build/asan -R 'tile_stream|hd_images' --output-on-failure
# 可选：用本地真实 40,432×4,800 背景检查驻留与远距离换区
xvfb-run -a ./build/dev/ef_tiled_render_tests content
python3 work/verify/verify.py
```

日志中 `upload_mode=preview_with_tiles` 明确标记小预览；`[tiles]` 给出原始像素、块大小与显存预算。

合成用例覆盖逐字节分块/apron、最后一行/列、跨会话缓存复用、损坏重建、取消与容量保护；真实 GL 像素与可整图上传的参考图比较，覆盖 4×/8×、alpha、接缝、跨块 atlas 裁剪、底裁与滤色。

后续顺序：`.ani` 八类头部与帧结构 → 原版设置/存读档外观、音乐鉴赏/回想入口 → KTX2 缓存与发布打包。

## 2026-10-29 验收结果

- dev 完整 44/44 PASS（78.02 秒）；ASan/UBSan 的 `tile_stream`、`hd_images` 2/2 PASS；M0 独立验证 PASS，失败 0。
- GL 合成逐像素对照通过：4×/8× 原倍率采样、透明度、块边缘、分数 atlas 裁剪、底裁、HSV/overlay/screen 原图坐标，以及异步细节补齐后的旧转场 FBO。CPU 队列压力检查覆盖多图层邻块占满时的新视口优先级。
- 真实 `bg/bg_scl008a01_03.png` 的 40,432×4,800 真 8× 源：初始视口 35 块，RGBA 纹理量 138,104,992 字节（131.71 MiB），另有预览 1.90 MiB；相对于完整 RGBA 740.33 MiB，仅驻留视口所需块。这里是纹理数据量，不是包含驱动/FBO/其它图层的整个进程显存。
- 远移至设计 x=-3900 后仍为 35 块 / 131.73 MiB，换区至细节齐备约 0.47 秒。首次建立缓存并补齐细节约 18.56 秒。这些时间来自 Debug + Xvfb/Mesa 软件 GL、并行回归环境，不作为实际显卡的性能保证。
- 左侧/远端真实截图已检查，无可见块网格或缺块；独立像素测试负责接缝数值验证。运行日志、PNG/PPM 截图仅保留于 `work/tile-*`，不提交素材。
