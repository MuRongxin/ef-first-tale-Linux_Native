# ANI 语音口型接入（2026-10-30）

本阶段将已解析的 `中口` / `開き口` 图块接入语音播放。基底仍为 4×/8×，局部动画图块保持原倍率；运行时只读 content，不读取原 exe、ANI 或 PAZ。

## REA 观察

原始游戏目录只读。取证输出、Evidence ID 和完整 bundle 留在 `work/re/lip-20261030/`，不提交游戏二进制或反编译输出。

- `0x5039d0 → 0x5027e0` 将语音接口保存在舞台对象；接口表 `0x577d7c` 的 `+8/+12` 分别返回包络和姓名。`0x4d6f30/0x4d6f20` 指向脚本引擎 `+0x1cac/+0x1c90`。姓名来自消息，不以语音文件名前缀猜测。
- `0x4f30e0` 去掉姓名开头 `@` / `#` 和空格，将结果存入 `+0x1c90`；空姓名清空。`0x4beeb0` 初始化十对姓名别名，`0x4be6e0` 查询别名。汉化 DLL 对十个中文名指针的替换已有 [汉化机制](07-汉化补丁机制.md) 取证。
- `0x5022c0` 比较姓名与动画角色，角色键可去掉首个小写 ASCII / `$`，以及末尾 `<...>`；姓名 `*` 匹配全部。输入包络 `+9` 的另一个全体匹配路径由语音 token `_all` 设置，实际 94 个脚本没有该标记，本轮没有扩展该 token 的资源解析。
- `0x4da8b0 → 0x4c5620` 将包络指针交给 Vorbis 播放器。`0x4c7840` 配置 16 段、每段 **8192 字节**的环形缓冲。
- `0x4c7250` 的通知路径在覆盖已播放的旧段之前累加每个有符号 PCM16 样本的绝对值，再除以 **4096 个交错采样字**；不是峰值或 RMS。`-32768` 的绝对值保留为 32768。输出为幅度 u32、递增编号 u32、活动标志。立体声每段 2048 帧，单声道 4096 帧。
- `0x4c5e80` 停止/结束时清空幅度和活动标志并增加编号；`0x4d7f00 → 0x500b60` 重置舞台口型，避免停在张嘴状态。
- `0x52cbf0` 的 800 阈值、幅度上升/下降及重复编号规则沿用 [ANI 状态机](ANI-FORMAT.md)。

主要本地证据：008–013（语音创建/停止）、020/032（解码线程）、030/033/034（接口表及回调）、041/044（振幅计算及缓冲尺寸）、050/062/066（别名）、052（匹配汇编）、068/069（消息姓名）、070（`_all`）。REA bundle 已导出，目标已关闭。

## 原生实现与策略边界

`make_voice_envelope` 在控制线程将解码的 float PCM 量化为 PCM16，按 4096 字预计算平均绝对幅度。尾段按零填充。Mixer 根据当前 voice 的源采样位置发布最近完整分段的幅度/编号；第一段播完之前幅度为零。音量、声像、BGM/SE 混音不改变包络；旧 voice 淡出尾音不再驱动口型。音频回调不新增解码、包络扫描、分配或释放。

`Presentation` 保存消息的角色身份；中文、原日文和原英文别名统一匹配 ANI 标签。`#` 隐藏姓名、`@` 匿名显示不丢失角色身份。未知/空姓名保持闭嘴；切换语音重置旧口型，显式停止立即重置，自然结束在下一场景更新重置。转场/震屏保留当前选择和旧快照，结束后重新消费最新包络。

原生存档 v1 可选增加 `presentation.lip_actor`，动画轨道增加 `lip` 数值状态。包络由已校验音频和保存的采样位置重建；保存并恢复已消费编号，避免重复消费。旧存档缺少字段仍可读：旧的纯口型轨道缺席时补闭嘴，旧档没有角色身份时安全保持闭嘴。

**未声称采样级保真**：当前 Vorbis 解码器为 stb_vorbis，原版为其自带解码器；float→PCM16 舍入可能不同。移植按播放游标选择最近完整分段，不模拟 DirectSound 环形缓冲的初始延迟、通知线程调度或设备输出延迟；原版轮询路径也未与通知路径等同。中文到 ANI 标签的 Unicode 桥接是移植实现，未运行汉化 DLL。跨 stage 对象复用、全局随机相位、高清图块与原版窗口逐帧对照仍是后续项。
