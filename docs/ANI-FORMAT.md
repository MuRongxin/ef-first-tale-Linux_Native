### REA 观察

构造器虚表确认三类对象：`EyeAnimater`（0x56018c）、`LipAnimater`（0x56023c）、`UniAnimater`（0x5602ec）。

- **眨眼**：`0x52cab0` 消费绝对时钟；同一时钟值不更新，每次最多切一个状态，超出的时间丢弃。序列为 `(状态编号, 停留量)` 对，负状态回到开头。`0x5aa054` 的六个指针指向 `0x573e68/0x573ed8/0x573f48/0x573fb8/0x574028/0x574098`。序列 0..4 每次回到首项额外加 `rand()%500+50`，序列 5 不加。构造器对未定义/越界配置使用默认序列 2；新核心接口要求调用者先完成配置选择，越界参数直接拒绝。
- **自定义循环**：`0x52be70` 执行命令序列，`@` 是循环标记，`~` 跳回标记；`name:duration` 选择命名图块并等待，`*:duration` 选择空图块/基底并等待。每次更新最多执行一个有时长状态，丢弃计时余量。核心仅接受实际 7 个文件使用的 `@;...;~` 正时长子集，坐标移动、其它 native opcode 和零时长尚未扩展；严格拒绝未知语法。
- **口型**：`0x52cbf0` 汇编确认输入三元组为数值幅度、更新序号、活动标志。重复序号忽略；活动且幅度 `>=800` 时，幅度上升令状态 `0→1`、其它状态 `→2`；幅度不升时，仅状态 1 且新幅度 `>=旧幅度>>1` 保持 1，其余回到 0。不活动/低于阈值时，状态 2 先退到 1，其余退到 0。`0x52c9d0` 根据数值状态查表选图。数值状态与具体名称的全局初始化映射仍待继续确认；核心输出数值状态，不假定名称。

`EyeClock` 的随机数由调用者注入，不声称复刻原版进程的全局 rand 消费顺序。时钟接口保留 native 整数单位，支持无符号回绕；宿主时钟单位、初始相位和更新频率还未闭合取证，未直接转换成秒。口型核心 `LipState` 接受原生包络数值，不在此猜测 PCM→幅度的算法。

### 实现

`tools/import_animations.py` 按清单 SHA-256 验证 ANI、配对图片和画布范围，输出原倍率 RGBA PNG 图块及 `ef.animations` v1 目录；控制串仍保留为 UTF-8 文本，由运行时严格解析已支持子集。全量导入 2,226 组 / 9,896 记录，其中 9,889 个位图记录；去重 PNG 目录约 91 MiB。现有 content 原子增加 `animations` 指针，剧本/音频/UI/图片档位不变；更新前 manifest 在 `work/ani-import/manifest.before.json`。`package_content.py` 的完整打包也包含该步骤。

```bash
python3 tools/import_animations.py --content content
```

动画目录与 `images` 高清档位契约分开，明确 `source_scale=1`。所有基底仍使用完整 4×/8×；**口眼/局部序列图块尚未高清重制**，与高清基底拼接时可能观察到清晰度差异，未把重采样冒充高清产物。运行时只读 content 的 JSON/PNG，不读 ANI、PAZ 或原始游戏目录。

`Content` 校验配对来源哈希、记录数量、整数画布范围和受限路径。`ImageAnimation` 由舞台加载创建，图层副本持有独立值状态。眨眼使用脚本 `EYE_SEQ_DEFAULT`（新宿主全局赋值通知）；自定义循环按原始 10ms 时序执行。旧包无动画目录时保持静态。原版随机数的全局消费顺序未复刻，本移植用源哈希播种的局部确定性随机源；同一存档恢复后保持一致。

Renderer 在各基底图层之后绘制所选局部图块、然后继续下一图层；图块自己的像素坐标映射到基底的设计空间。底裁/图集取交集，滚动和 WScroll2 的图层副本沿用同一帧状态；HSV→overlay→screen 使用基底 UV 与底锚点。图块缓存独立限制 **64 MiB**，解码前检查尺寸/预算，不污染普通高清档位选择。透明度通过现有场景混合路径处理。

转场和震屏期间保留图块选择，计时继续；恢复更新时按原版丢弃时间余量的规则切换一项。旧舞台拷贝冻结动画；窗口改变档位重建 FBO 时沿用相同状态。每个 stage 创建新播放器是本轮的明确实现策略；原版跨同名 stage 的角色对象复用/随机相位仍未逐帧对拍。

存档 v1 的图层对象可选增加 `animation`，保存来源哈希、序列档、局部时钟、随机种子、各轨道位置和剩余量。读档校验结构、游标、帧名、时间范围和来源身份；损坏或来源变化拒绝。旧档没有该字段仍可读，并保持原有静态图层，下一次 stage 重新绑定动画。全局眼序列选择从已存变量恢复。
