## 已观察：.shakeScreen

- 解析器 004e6460 要求三个参数；执行器 004e6770 → 004d9bf0，分别传递模式、幅度、时长。
- 大小写无关地检查模式首字符：Z=5、V=6、H=7、O=9、T=10；其他（包括数字字符串 `2`）在正时长下走类型 8。负时长会进入另一处理路径，移植版暂时严格拒绝。
- 幅度按 800×600 虚拟像素使用；时长绝对值设置到 10ms 倒计时。绘制间隔读取 shakeDrawInterval；本安装值 3，即 30ms。
- 004e11a0 的震屏状态分支在活动期间返回，完成时还原原始帧并继续脚本。因此连续指令必须逐次完成，不能覆盖前一次。
- 类型 8：随机值 &7 后的 switch 有成对分支。每个移动函数都从冻结原图重绘，因此 fallthrough 的第二次移动覆盖第一次；最终是左/右/下/上四个方向，各对应两个随机值。不是对角平移。00524350 是 ESI 源到 EDI 目标的位图复制，不能误记为屏幕呈现。
- H/V：左右/上下交替，移出部分填黑；固定幅度，不把幅度再除十。
- Z：0051f290 将 `(a,a,800-a,600-a)` 区域用最近邻放大为全屏，与原图交替；首次绘制放大图。
- O：rand() % (2*a) - a；CRT 分派描述 00585990 包含 `fmod`，角度转为弧度后调用 00523330 → 0051f110，以 (400,300) 为中心，越界填黑。后者使用 1024 倍三角函数系数并截断，与逐像素整数寻址。005434c8 的 FSIN / 00543398 的 FCOS 确认了系数身份；源坐标为 `(c*dx-s*dy+400,s*dx+c*dy+300)`，不能颠倒旋转符号。
- O 的 0051f030 对旋转结果与上次历史逐字节取 floor((new+old)/2)，再把历史复制回画面；不是纯旋转。
- 语料 17 次调用均覆盖在 R / 数字默认 / Z / O 模式中；T 未实现，继续报错。

## 已观察：.overlay

- CommandOverlay 表 00576b84，解析 004eb9a0，执行 004ebcf0 → 004dd5f0。
- 双参数是背景、前景；三参数是边框、背景、前景。空值或 `*` 清除；省略边框也清除边框状态。只设置下一次场景的材质，不触发绘制或等待。
- 场景处理顺序为 HSV → overlay → screen。源图与色带底部对齐，色带上方不足部分重复首行。
- 005202c0 按源 RGB 每通道的高位分支，设 a=源通道，b=色带通道：
  - a<128：min(255, 2*((a*b+255)>>8))。
  - a>=128：255-min(255, 2*(((255-a)*(255-b)+255)>>8))。
- 保留 alpha；透明像素跳过。不能用乘法或标准浮点 overlay 混合函数代替此整数舍入。

## 移植实现与边界

- Shake 使用相对时钟、固定种子的 CRT LCG 与 30ms 采样，避免依赖系统 rand 全局调用顺序。这是移植版选择；原版的全局种子及其他命令消耗的随机数尚未复现。
- OpenGL 直接冻结当前物理分辨率下的完整游戏画布（含消息 UI），采用最近邻变换；保留高清资源。重绘同一样本不重复叠影。窗口变化或清缓存会重建冻结图与历史。
- 原版固定 800×600 的整数旋转栅格与高清物理像素映射并非同一栅格，尚未完成原版运行截图逐像素对照。
- overlay/screen 在 GPU 采样源图后计算；原版先处理源位图再采样，非均匀图像边缘的插值顺序有差异（同 SCREEN-20261026.md 的限制）。
- 色带使用独立缓存；加载第二个滤色纹理时固定第一个，避免同次绘制中被 LRU 回收。
