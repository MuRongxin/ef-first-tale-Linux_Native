# 窗口存读档菜单与缩略图（2026-10-28）

已把 `SaveMenuLayout`、普通/快速槽位存储与 SDL/OpenGL 窗口接通。原版静态坐标及导航表沿用 [布局取证](SAVE-MENU-LAYOUT-20261028.md)；本轮没有新增原版逆向结论。

## 操作与数据位置

- F4 / 鼠标右键：保存菜单；F12：读取菜单。Tab 或点击左下角在存读模式间切换。
- 方向键选槽，PageUp/PageDown 翻页，Home/End 首末页，Enter 提交，Esc / 右键返回。鼠标同一热区按下/释放选槽，再次点击或双击提交。
- 保存模式只显示普通页 1～10，共 100 槽；读取模式可到第 0 页，显示 q1～q9。自动档位置仍不可操作。
- 保存需确认，Enter/Y 或点击确定；Esc/N 或点击取消退回菜单。取消不写盘。没有新增备注编辑器。
- 菜单使用 `--save-dir`；省略时用 `$XDG_DATA_HOME/ef-native/saves/slots`（HOME 回退）。F2/F3 保留原来单文件或槽位模式。单文件 quick.json 不会自动列入槽位菜单。
- 普通窗口与最大化/全屏沿用 4×/8× 选择；命中点经物理像素视口转换，黑边不命中。菜单中 F10/F11 仍可切换窗口状态。

运行时只读 content。`import_scripts.py` 导入布局为按 SHA-256 命名的 blob，在剧本索引增加 `save_ui`。已有包运行：

```bash
python3 tools/import_scripts.py --refresh-ui
```

只刷新 UI 不改变剧本、资源和既有存档绑定；无新布局的旧包在打开菜单时报错并保留当前会话，F2/F3 仍可用。

## 暂停、失败隔离与截图

菜单打开前冻结剧情更新，并暂停 SDL 音频设备；关闭后恢复设备、重置固定步时钟，菜单停留时间不会补进剧情。影片期间不打开菜单。保存沿用 settled 手动对白/选项限制；读取菜单可在其它非影片演出中打开。恢复仍先完整构建、校验、预载候选会话，再交换现有会话；失败保留菜单和原进度。

100×75 截图从当前已合成的游戏视口缩小读取，包含消息窗/NVL、场景特效和文字，不含菜单、通知或窗口黑边。像素转为顶行在前的固定 RGB8 十六进制数据，存到 `ef.save` v1 的可选 `thumbnail` 字段：`format=rgb8-hex`、`width=100`、`height=75`、`pixels` 长度严格为 45000。RGBA 解码补不透明 alpha；非法尺寸、长度、字符或多余字段拒绝。旧七字段 v1 存档仍兼容。

截图在保存点捕获，与 VM/场景状态放进同一个 JSON 对象，由既有槽位锁、对象写入和 catalog 原子发布流程处理；不会出现新存档配旧截图的旁路文件。F2 窗口保存同样生成截图；CLI trace 保存没有 GL 上下文，不生成截图。旧档/无图档显示 notsaved 占位图，损坏或不兼容槽位禁止读取，允许确认覆盖。

## 界面实现边界

底图、选中装饰、空缩略图使用 content 中的原版资产，槽位/控制热区与原版静态表一致。槽号、时间、正文摘要、模式切换、页码、确认框由 FreeType/矩形原生绘制；完整标题/按钮图集、动画、菜单音效及备注编辑尚未复刻，本轮不声称原版截图逐像素一致。100 个普通槽位与额外第 10 页仍为移植扩展。
