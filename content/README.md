# content — 运行时数据

运行 `python3 tools/prepare_content.py`，从已解包图像、已完成的高清产物与本机中文字体
准备一个独立预览包。此目录中只有本 README 入库，所有游戏素材、字体副本与生成清单均忽略。

`ef_native --content content` 只从该目录加载素材/场景/字体，不访问原始游戏或 `assets/`。
复制整个目录即可搬迁预览数据；不要用指向包外的软链接代替导入。

默认包含 1× 开发回退及已有的 4×/8×；`--hd-only` 不带 1×。
导入器按内容哈希存放 blob，并最后原子替换 `manifest.json`；运行中按 R 可重载。
旧 blob 暂不自动清理，避免正在运行的进程失去引用；这仍是预览导入器，不是最终内容打包器。

构建与准备数据的命令见 [项目 README](../README.md)。
